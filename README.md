# 수입 주류 원가·시장 리포트 에이전트 (2차, 11월 범위)

수입 후보(제품명·현지 가격·구매 국가)를 넣으면 FTA 판정을 반영한 **도착 원가**와 원산지국 해당 품목의 한국 **수입 추이**를 담은 리포트(PDF)를 만듭니다. 후보를 등록해 두면 환율·세율·현지가가 움직였을 때 **월간 변동 알림**으로 원인을 나눠 알려 줍니다.

**목적**: 관세사·포워더 견적을 받기 전에, 여러 후보 가운데 견적을 받아 볼 만한 후보를 빠르게 거르는 1차 검토 도구입니다. 결과는 **참고 원가**입니다. 운임·보험료·통관비는 거래마다 달라 가정값(`config/assumptions.json`, 기본 0원)으로 계산하고, 리포트에 견적 금액을 반영하는 보정표(운임·보험료 1원당·통관비 1원당 증가액)를 함께 넣습니다.

## 2차에서 달라진 것 (10월 발표의 「11월 말까지 완성할 범위」 대비)
| 범위 | 약속한 기준 | 지금 상태 |
|---|---|---|
| 지원 주종 | 종가세 6종 이상 + 종량세 2종 | 종가세 8종(위스키·와인·사케·브랜디·럼·진·보드카·데킬라) + 종량세 2종(맥주·탁주) |
| 계산 정확도 | 공개 계산 사례 3건 이상, 엑셀 독립 계산 20건 오차 1원 이내 | 엑셀 20건 모두 일치(`docs/verification/`). 공개 사례는 기사 2건(세 번째는 찾는 중) |
| 세율 정확도 | 규칙표 샘플 10건 중 9건 이상 공식 조회와 일치 | 규칙표 1,060행을 관세율표 2026 파일에서 생성. 공식 화면 대조 목록은 `docs/verification/CHECKLIST_공식조회_대조.md`(사람이 확인) |

| 월간 알림 | 후보 3개 이상에서 ±5% 변동 시 환율·세율·현지가 원인 분해 알림 | `run_watch.bat`. 시연 후보 5건 모두 알림 생성(`watchlist/reports/`) |
| 도매가 대응 | 견적가 입력 지원, 가격 종류 표기 | 가격 종류(소매가 / 도매·견적가)를 고르면 리포트·근거표에 표기 |
| 웹앱 배포 | URL 접속만으로 리포트 생성 | 웹앱 코드 완성, 이 PC에서 동작 확인(`run_webapp.bat`). 외부 배포는 `docs/DEPLOY_WEBAPP.md` 절차대로 진행 |
| 실행 시간 | 후보 1건 1분 이내 | 실시간 조회 포함 수 초 |

## 받기 (구글 드라이브 링크로 받은 경우)
1. 링크를 열면 보이는 `liquor-import-agent` **폴더 전체**를 받습니다. 폴더 이름 옆 ▾ 또는 ⋮ → 「다운로드」를 누르면 드라이브가 zip 하나로 묶어 줍니다. `liquor-import-agent.zip` 파일이 따로 보이면 그 파일 하나만 받아도 같습니다.
2. 받은 zip을 우클릭 → 「압축 풀기(모두 추출)」 합니다. zip 안에서 바로 실행하면 동작하지 않습니다.
3. 압축을 푼 폴더에서 `run_gui.bat`이 보이는 곳까지 들어갑니다(같은 이름 폴더가 한 겹 더 있을 수 있음).

- 필요한 것은 **Python 3.9 이상**뿐입니다. 작은 패키지(reportlab)는 처음 실행할 때 자동으로 설치됩니다. 환율·무역통계 **API 키(무료 공공데이터 키)는 이 폴더의 `api_keys.env`에 들어 있어** 별도 설정 없이 실시간으로 조회합니다.
- Python이 없으면 안내 문구가 나옵니다. https://www.python.org/downloads/ 에서 설치하고 첫 화면의 **「Add python.exe to PATH」를 체크**한 뒤 다시 더블클릭합니다.
- 「Windows의 PC 보호」 창이 뜨면 「추가 정보 → 실행」을 누릅니다(인터넷에서 받은 파일에 붙는 일반 경고).
- 막히면 폴더의 `START_HERE.txt`를 보세요.

## 입력 창 사용법 (`run_gui.bat`)
창 아래쪽에 「실시간 모드(API 키 있음)」가 보이면 환율·무역통계를 실시간으로 조회하는 상태입니다. **필수는 제품명·현지 가격·구매 국가 3칸**이고 나머지는 비워 두거나 기본값 그대로 두어도 됩니다.

### 1) 주 입력 창
| 칸 | 필수 | 넣는 값과 예시 | 비워 두면 |
|---|---|---|---|
| 제품명 | 필수 | 제품 이름. 주종 단어(위스키·와인·맥주·Beer·Vodka 등)나 브랜드(야마자키, 맥캘란, 아사히, 헤네시 등), 용량(700ml, 70cl)을 넣으면 자동 인식이 잘 됩니다. 예: `Macallan 12 Scotch Whisky 70cl` | 진행 안 됨 |
| 현지 가격(숫자) | 필수 | 현지에서 확인한 **1병 가격(현지 통화)**. `22500`, `22,500`, `22500엔`, `29.99` 모두 됩니다. 에이전트는 가격을 수집하지 않으므로 직접 확인해 넣습니다. | 진행 안 됨 |
| 가격 종류 | 선택 | 소매가 / 도매·견적가. 리포트와 근거표에 표기됩니다(계산식은 같음) | 소매가 |
| 구매 국가 | 필수 | 목록에서 고르거나 직접 입력. 한글(`일본`), 영문(`Japan`, `United Kingdom`), 코드(`JP`) 모두 됩니다. 칸 아래에 통화가 자동으로 표시됩니다. | 진행 안 됨 |
| 주종 | 선택 | 「자동 인식」 / 위스키 / 와인 / 사케(청주) / 브랜디 / 럼 / 진 / 보드카 / 데킬라 / 맥주 / 탁주(막걸리) | 제품명으로 자동 인식. 인식하지 못하면 안내가 나오니 이 칸에서 고릅니다. |
| 품목 코드(HS) | 선택 | 「자동 인식」, 목록 17개, 「직접 입력…」(10자리, 예: `2208309000`) | 주종과 제품명으로 자동 제안. 시장 추이는 이 코드로 조회합니다. |
| 용량(ml) | 맥주·탁주는 필수 | `700`, `700ml`, `70cl`, `0.7`(리터로 읽음). **맥주·탁주는 용량에 세금이 붙는 종량세라 꼭 필요합니다.** | 제품명에 용량이 있으면 그 값. 종가세 주종은 없어도 되며 「가격 위치」만 빠집니다. |
| 마진율(%, 선택) | 선택 | 도착 원가에 붙일 마진. `25`, `25%`, `0` (0~300). 예상 소비자가 = 도착 원가 × (1 + 마진율) | 30%로 가정하고 리포트에 「30%(가정)」으로 표시 |
| FTA 질문 1 | 선택 | 원산지 국가에서 생산된 제품인가: 모름 / 예 / 아니오 | 「모름」 |
| FTA 질문 2 | 선택 | 거래처가 원산지증명서를 발급할 수 있나: 모름 / 예 / 아니오 | 「모름」 |

FTA 판정 규칙(창에도 표시됨): 두 질문이 모두 「예」이고 구매 국가와 원산지가 같으면 **협정세율 적용 가능**, 하나라도 「아니오」이면 **일반세율**, 「모름」이 있으면 **확인 필요**(협정세율·일반세율 두 원가를 나란히 표시)입니다. 구매 국가와 원산지가 다르면(경유 구매) 「확인 필요」가 됩니다. 협정이 없는 생산국(멕시코·러시아·대만 등)은 「적용 불가」로 일반세율만 계산합니다. 규칙표의 협정세율이 적용 기간을 지난 값이면(한-EU·한-영 일부) 「확인 필요」로 표시합니다.

### 2) 세부 설정 (선택, 「세부 설정 보기」 체크 → 작은 창이 따로 열림)
| 칸 | 쓰는 경우 |
|---|---|
| 제품명으로 제안 받기(버튼) | 주종·품목 코드·원산지·용량·도수 제안값을 미리 채워 보고 고칠 때 |
| 통화 | 구매 국가로 통화를 알 수 없을 때(예: `MXN`). 보통은 자동 |
| 원산지 국가 코드 | 구매 국가와 원산지가 다를 때(예: 일본에서 산 스카치 → `GB`) |
| 도수(%) | 가격 위치 계산에 씀. 비우면 제품명에서 읽거나 주종 기본값 |
| **국내 판매가(원)** | 국내에서 같은 제품이 팔리는 가격. **넣으면 리포트에 4장(국내가 비교)이 추가되고, 결론이 「예상 소비자가가 국내 판매가보다 높다/낮다」는 가격 판단으로 나옵니다.** |
| 가격 출처 URL | 현지 가격을 확인한 판매처 주소. 리포트 출처 목록에 들어갑니다 |
| 과세환율 직접 입력 | 실시간 환율 조회가 안 될 때 관세청 고시값(원/통화 1단위)을 알고 있으면 입력 |
| 샘플 모드 / 샘플 저장(체크) | 저장된 API 응답으로 실행하거나, 받은 응답을 저장할 때. 평소에는 체크하지 않습니다 |

### 3) 리포트 만들기와 결과
1. [리포트 만들기]를 누르면(제품명·가격 칸에서 Enter도 됨) 몇 초 뒤 리포트 PDF가 자동으로 열립니다.
2. 창 아래 결과 칸에 요약이 나옵니다: 자동으로 정한 주종·HS 코드·원산지, 도착 원가와 예상 소비자가, FTA 판정, 견적 보정 안내, 마진율, 가격 위치.
3. 파일은 `outputs/runs/<주종_날짜시각>/`에 저장됩니다: 리포트 PDF·HTML, `facts.csv`(숫자별 근거), `result.json`(계산 결과 전체).
4. 리포트는 **참고 원가**입니다. 견적을 받으면 리포트 요약 쪽 「견적을 받으면 이렇게 보정한다」 표로 금액을 더합니다.
5. **[월간 알림에 등록]** 을 누르면 방금 계산한 후보가 지금의 환율·세율·현지가를 기준으로 저장됩니다. **[월간 변동 확인]** 을 누르면 등록 목록이 열리고, 현지가가 바뀐 후보는 「새 현지가」 칸에 넣은 뒤 확인하면 알림 리포트가 열립니다.

### 4) 이런 안내가 나오면
| 안내 | 할 일 |
|---|---|
| 「…계열은 지원 주종이 아닙니다」 | 소주·리큐르·고량주 등은 아직 지원하지 않습니다 |
| 「맥주는 용량에 세금이 붙는 종량세 주종입니다」 | 맥주·탁주는 용량(ml) 칸을 채웁니다(예: 330, 500) |
| 「제품명에서 주종을 알 수 없습니다」 | 주종 칸에서 고르거나 품목 코드를 선택합니다 |
| 「주종과 품목 코드가 맞지 않습니다」 | 둘 중 하나를 「자동 인식」으로 돌리거나 서로 맞춥니다 |
| 「…의 통화를 알 수 없습니다」 | 세부 설정 창이 자동으로 열리니 통화 코드를 넣습니다 |
| 「과세환율을 실시간으로 받지 못했습니다」 | 인터넷 문제나 API 호출 한도 소진입니다. 잠시 후 다시 시도하거나, 세부 설정에 과세환율을 직접 넣습니다(저장된 자료로 대신 계산하지 않습니다) |
| 리포트의 시장 추이가 「조회 실패」 | 무역통계만 받지 못한 경우입니다. 원가 계산은 정상이고, 잠시 후 다시 만들면 추이가 채워집니다 |

## 월간 변동 알림 (`run_watch.bat`, `src/watch.py`)
등록한 후보의 도착 원가가 **등록 시점보다 ±5% 이상** 움직이면 알림으로 표시하고, 변동을 환율 → 세율 → 현지가 순서로 나눠 보여 줍니다(세 효과의 합 = 전체 변동). 직전 확인 대비 변동도 함께 나옵니다.
```
python src/watch.py add --input inputs/candidate_whisky.json     후보 등록(지금의 환율·세율·현지가가 기준)
python src/watch.py add --name "Asahi Super Dry 350ml" --price 220 --country 일본
python src/watch.py list                                         등록 목록
python src/watch.py price w1 23500                               현지가 갱신(자동 수집하지 않으므로 직접 넣음)
python src/watch.py check                                        변동 확인 → watchlist/reports/alert_날짜.pdf
python src/watch.py check --threshold 3                          이번만 기준을 ±3%로
python src/watch.py remove w1                                    등록 삭제
```

## 웹앱 (`run_webapp.bat`, `webapp/streamlit_app.py`)
설치 없이 브라우저에서 쓰는 화면입니다. 입력 창과 같은 계산 코드를 씁니다. 왼쪽에 「후보 입력」이 고정되어 있고, 오른쪽 위에 「리포트 만들기」, 「월간 변동 알림」, 「사용 안내」 세 탭이 있습니다. 결과는 결론 띠와 숫자 카드로 먼저 보여 주고, 그 아래 「리포트 / 원가 분해 / 시장 추이 / 요약과 파일」로 나눠 봅니다. 색은 리포트와 같은 파란색 계열이며 `.streamlit/config.toml`에서 정합니다. 리포트는 만든 자리에서 화면에 전체가 펼쳐져 바로 볼 수 있고, 원하면 [리포트 PDF 받기]로 화면과 같은 모양의 PDF를 받아 갑니다(HTML·근거표·계산 결과도 받을 수 있음). 월간 알림 리포트도 같습니다. 외부에 올리는 방법(API 키는 서버의 Secrets에만 둠)은 `docs/DEPLOY_WEBAPP.md`에 있습니다.

## 리포트 형식 (교수 제공 스킬 `report_style/` 적용)
- `report_*.html`: 스킬 규칙(A4 세로 판면과 여백, 본문 8.5pt 등 글자 크기 범위, 한 색 계열, 가로줄 표, 결론형 제목, 비교 대상이 붙은 숫자, 그림·표마다 출처 줄)으로 만든 보고서. 읽기 쉽게 표지 요약표, 결론 띠, 장별 결론 목록, 계산 흐름 그림, 판정 상자, 수치 카드, 쪽 번호를 넣었습니다(규칙 범위 안의 배치 변경)
- `report_*.pdf`: 위 HTML을 Edge 또는 Chrome으로 인쇄한 PDF. 브라우저가 없으면 기본 PDF로 대신하며 안내 문구가 나옵니다.
- `facts.csv`: 보고서 숫자의 근거 목록(값, 출처, 기준일), `result.json`: 계산 결과 전체
- 문장은 코드 템플릿이며 숫자는 계산값을 그대로 씁니다. 만들 때마다 스킬의 한글 검사기(`report_style/scripts/check_korean.py`)로 금지어를 검사합니다. 월간 알림 리포트도 같은 규칙을 따릅니다.
- 표지 작성자 이름은 `config/report_settings.json`의 `author`에서 바꿉니다.

## 계산 규칙
- 종가세(위스키·브랜디·럼·진·보드카·데킬라 주세 72%, 와인·사케 30%): 과세가격 = (현지가 + 운임 + 보험료) × 관세청 과세환율 → 관세 = 과세가격 × 관세율 → 주세 = (과세가격 + 관세) × 주세율 → 교육세 = 주세 × 30%(주세율 70% 초과) 또는 10% → 부가세 10%
- 종량세(맥주·탁주): 주세 = 용량(리터) × 리터당 세액(맥주 885.7원, 탁주 44.4원). 교육세는 맥주가 주세의 30%, 탁주는 없음. 나머지는 같습니다. 생맥주(8L 이상 용기) 20% 경감은 반영하지 않습니다.
- 세율은 `config/tax_rules.csv`(주세·교육세)와 `config/fta_rules.csv`(HS 코드 × 원산지별 관세율 1,060행, `tools/build_fta_rules.py`가 관세청 관세율표 2026에서 생성)에 있습니다.

## 가격 위치 (시장에서 후보 가격이 어디쯤인가)
입력가(과세가격)를 USD 과세환율로 달러로 바꾸고 순중량(용량 × (1 − 0.0013 × 도수) kg/L)으로 나눠 **달러/kg 단가**를 만든 뒤, 같은 품목·원산지의 최근 12개월 평균 수입단가와 견줍니다(리포트 3장). 용량을 모르면 계산하지 않으며, 도수를 모르면 주종별 기본값을 쓰고 표시합니다. **근사값**입니다: 무역통계 단가는 품목 전체 평균이라 소매가로 넣은 후보는 높게 나옵니다.

## 한계

- 소주·리큐르·고량주, 국내 판매가 자동 조회, LLM 제품 정보 제안은 지원하지 않습니다.
- 리포트의 세액과 FTA 판정은 참고용이며 법률·세무 자문이 아닙니다.
