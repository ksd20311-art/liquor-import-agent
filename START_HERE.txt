1. run_gui.bat 을 더블클릭하세요.   <- 기본 실행 방법
   -> 입력 창이 열립니다. 제품명, 현지 가격, 구매 국가를 직접 입력하고 FTA 질문 2개에 답한 뒤 [리포트 만들기]를 누르면
      도착 원가·FTA 판정·시장 추이가 담긴 리포트(PDF)가 만들어져 열립니다.
      (환율·무역통계 API 키는 이 폴더의 api_keys.env 에 들어 있어 따로 설정할 것이 없습니다. 필요한 것은 Python뿐입니다)
   -> 예) 제품명 Macallan 12 Scotch Whisky 70cl / 가격 70 / 구매 국가 United Kingdom
   -> 예) 제품명 Asahi Super Dry 350ml / 가격 220 / 구매 국가 일본   (맥주·탁주는 용량이 꼭 있어야 합니다)
   -> 지원 주종: 위스키, 와인, 사케, 브랜디, 럼, 진, 보드카, 데킬라, 맥주, 탁주
   -> 마진율(%)과 가격 종류(소매가 / 도매·견적가)는 선택 입력입니다. 마진율을 비우면 30%로 가정합니다.
   -> 국내 판매가(원)는 「세부 설정 보기」를 체크하면 열리는 작은 창에 있습니다. 넣으면 리포트에 국내가 비교(4장)가 추가됩니다.
   -> 칸마다 무엇을 넣는지, 안내 문구가 나올 때 할 일은 README.md 의 「입력 창 사용법」에 자세히 있습니다.

2. run_watch.bat 을 더블클릭하면 월간 변동 알림 리포트(PDF)가 열립니다.
   -> 등록해 둔 후보의 도착 원가가 등록 시점보다 ±5% 이상 움직였는지, 환율·세율·현지가 가운데 무엇 때문인지 보여 줍니다.
   -> 지금 들어 있는 후보 5건은 시연용입니다(등록 기준일을 2026-07-27로 소급, 야마자키 외에는 예시 가격).
   -> 내 후보를 넣으려면 입력 창에서 리포트를 만든 뒤 [월간 알림에 등록]을 누르세요. [월간 변동 확인]으로 같은 리포트를 볼 수 있습니다.
