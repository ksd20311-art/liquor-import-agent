# 웹앱 배포 안내

웹앱은 `webapp/streamlit_app.py` 하나입니다. 계산은 입력 창과 같은 코드(`src/`)를 씁니다.

## 1. 이 PC에서 먼저 확인
`run_webapp.bat`을 더블클릭하면 브라우저에 화면이 열립니다(처음 한 번은 streamlit 설치로 몇 분 걸립니다).
이 방식은 이 PC에서만 열립니다. 다른 사람이 URL로 접속하게 하려면 아래처럼 외부에 올려야 합니다.

## 2. 외부에 올리기 (Streamlit Community Cloud, 무료)
직접 하셔야 하는 단계입니다(계정 생성과 API 키 등록이 들어 있음).

1. **GitHub 저장소 만들기**: github.com에 가입하고 새 저장소를 만든 뒤 이 폴더를 올립니다.
   - **`api_keys.env`와 `.env`는 올리지 않습니다.** `.gitignore`에 들어 있는지 확인하세요. 키는 4번에서 서버에만 넣습니다.
   - `data/raw/`(관세율표 원본 22MB)도 올릴 필요가 없습니다.
   - `.streamlit/config.toml`(화면 색 설정)과 `packages.txt`는 **꼭 함께 올립니다**. 점으로 시작하는 폴더라 빠뜨리기 쉽습니다.
2. **share.streamlit.io** 에 GitHub 계정으로 로그인하고 「Create app」을 누릅니다.
3. 저장소와 브랜치를 고르고 **Main file path**에 `webapp/streamlit_app.py`를 넣습니다.
4. **Advanced settings → Secrets**에 아래처럼 키를 넣습니다(따옴표 포함).
   ```
   DATA_GO_KR_KEY_FX = "관세환율정보 일반 인증키(Decoding)"
   DATA_GO_KR_KEY_TRADE = "품목별 국가별 수출입실적 일반 인증키(Decoding)"
   ```
   두 서비스가 같은 키면 `DATA_GO_KR_KEY = "..."` 한 줄만 넣어도 됩니다.
5. 「Deploy」를 누르면 몇 분 뒤 `https://<이름>.streamlit.app` 주소가 생깁니다. 이 주소를 RITA에 등록합니다.

## 3. 올린 뒤 확인할 것
- 화면 위에 「API 키가 없어 … 샘플 모드」 경고가 **없어야** 실시간 조회 상태입니다.
- 제품명 `Asahi Super Dry 350ml`, 가격 `220`, 국가 일본으로 리포트가 나오는지 확인합니다.
- 리포트가 화면에 전체로 펼쳐지는지, **[리포트 PDF 받기]** 로 받은 PDF가 화면과 같은 모양이고 한글이 깨지지 않는지 확인합니다.
  - PDF는 서버에 설치된 Chromium으로 만듭니다(저장소의 `packages.txt`가 Chromium과 나눔 글꼴을 설치).
  - Chromium이 없으면 기본 형식의 PDF로 대신하고 화면에 그 사실을 알립니다. 그것도 안 되면 HTML을 받아 브라우저에서 인쇄(Ctrl+P)하라고 안내합니다.

## 4. 알아 둘 점
- **호출 한도**: 공공데이터 개발계정 키는 하루 호출 수에 한도가 있습니다. 한 접속에서 만들 수 있는 리포트를 40건으로 막아 두었지만(`MAX_RUNS`), 여러 사람이 쓰면 한도에 닿을 수 있습니다. 한도에 닿으면 저장된 자료로 대신하지 않고 원인을 안내합니다.
- **월간 알림 목록**: 웹에서는 접속이 끝나면 목록이 지워집니다. 「목록 파일 받기」로 저장했다가 다음에 다시 올려 이어서 씁니다.
- **PDF와 한글 글꼴**: 저장소의 `packages.txt`가 서버에 Chromium(PDF 인쇄용)과 나눔 글꼴을 설치합니다. PDF를 만드느라 리포트 한 건에 몇 초가 더 걸립니다.
- 다른 서비스(Render, Hugging Face Spaces 등)에 올릴 때는 시작 명령을 `streamlit run webapp/streamlit_app.py`로 하고, 키를 그 서비스의 환경 변수에 같은 이름으로 넣으면 됩니다.
