- 2208309000(기타 위스키): 구분 `FRCJP1`(RCEP 일본) **13.3%**, 구분 `A`·`C` 30%, 구분 `F` 20% (적용 2026-01-01~12-31).
  - 2208302000(버번)만 RCEP 일본 10%. 2208301000·2208303000도 13.3%.
  - 기본세율 구분 코드의 의미(F=20%가 일반 적용세율인지)는 UNI-PASS 안내로 확인 필요. 가이드의 일반세율 20%와 값은 일치함.
- HS부호 파일은 10자리 코드와 품목명을 포함 (12,469행). 2208301000 스카치, 2208302000 버번, 2208303000 호밀, 2208309000 기타.
- 위 값을 `config/fta_rules.csv`(JP,whisky,RCEP,2026,0.133)와 `config/hs_map.csv`에 반영함. 갱신: 관세율표 연 1회.

참고: 같은 과세환율을 tradedata.go.kr 「관세환율정보」 화면(수입(과세))에서 직접 확인해 `config/customs_fx.csv`에 기록함

## FTA 규칙표 자동 생성 (2026-10-29)
- `config/fta_rules.csv`(304행)는 `tools/build_fta_rules.py`가 관세청 품목번호별 관세율표 XLSX(공공데이터 15051179)에서 만든다. HS 코드별(위스키 4종, 청주 1종, 포도주 3종) × 원산지 국가별(EU 27개국, 미국, 영국, 호주, 캐나다, 칠레, 중국, 인도, 일본, 뉴질랜드, 튀르키예, 베트남) 협정세율과 일반세율(구분 F)을 담는다.
- 파일에는 한-EU·한-영 협정세율이 2026-06-30까지만 있어(7월 이후 값은 파일에 없음), 이 값은 `status=period_ended`로 표시되고 FTA 판정이 「확인 필요」(협정·일반 두 원가 병기)가 된다.
- 예외: 2208309000 한-EU는 UNI-PASS 화면(0%, 2026-07-01~2027-06-30)으로 확인해 유효 처리(`VERIFIED_EXTENSIONS`).
- 갱신: 새 관세율표 파일을 받으면 `python tools/build_fta_rules.py 파일.xlsx 기준일`을 다시 실행.
