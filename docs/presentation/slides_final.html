5. 환율 수집·가격 종류·웹앱

주간 환율 기록과 웹 화면을 더했고, 외부 배포는 남아 있습니다

과세환율 주 1회 수집

  • 관세청 API로 그 주의 전체 통화를 받아 기록합니다(같은 주는 한 번만).
  • 기록 53주(2025-11-16 ~ 2026-11-15 주간), 통화 58개
  • 같은 기간 엔화는 100엔당 955.74원(2026-07-05) ~ 842.77원(2026-10-25)

지금 기록은 2026-11-16에 한꺼번에 받은 것입니다. 매주 자동 실행은 작업 스케줄러 등록 배치로 하며, 등록은 사용할 PC에서 직접 해야 합니다.

가격 종류 표기

  • 현지 가격이 소매가인지 도매·견적가인지 고릅니다.
  • 리포트의 입력 정보와 근거표에 표기됩니다.
  • 계산식은 같습니다. 운임·통관비 견적은 리포트의 보정표로 반영합니다.

견적을 받아야만 쓸 수 있는 도구가 되지 않도록, 입력은 가격 종류 선택까지만 넣었습니다.

웹앱

  • 입력 창과 같은 계산 코드를 쓰는 웹 화면(리포트 만들기, 월간 변동 알림, 사용 안내)
  • 이 PC에서 리포트 생성과 알림 등록·확인까지 동작 확인
  • 외부 배포와 RITA URL 등록은 아직 하지 않았습니다. API 키를 서버에만 두는 절차를 문서로 남겼습니다.
