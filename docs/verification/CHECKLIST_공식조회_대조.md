# 세율 공식 화면 대조 목록 (사람이 확인해 채우는 표)

11월 성공 기준 「규칙표 샘플 10건 중 9건 이상 공식 조회와 일치」를 확인하기 위한 표입니다. 에이전트가 대신 확인할 수 없는 단계라 「공식 화면 값」 칸을 비워 두었습니다.

확인 방법: 관세법령정보포털(unipass.customs.go.kr/clip)의 국내 주요 세율에서 품목번호 10자리를 조회하거나, YES FTA 포털의 「FTA 수입세율 조회」에서 국가와 품목번호를 넣습니다. 화면을 캡처해 `inputs/evidence/`에 두면 근거가 남습니다.

규칙표 값은 `config/fta_rules.csv`(관세청 품목번호별 관세율표 2026 파일, 2026-11-16 내려받음)에서 그대로 옮긴 것입니다.
