계산 방법

과세가격 = (입력가 + 운임 + 보험료) × 과세환율. 관세 = 과세가격 × 관세율. 주세 = (과세가격 + 관세) × 주세율(72%). 교육세 = 주세 × 30%. 부가세 = (과세가격 + 관세 + 주세 + 교육세) × 10%. 도착 원가 = 위 합계 + 통관·국내운송비. 예상 소비자가 = 도착 원가 × (1 + 마진율).

비워 둔 항목: 실제 운임·보험료·통관비, 현지가 자동 수집. 세액과 FTA 판정은 참고용이며 법률·세무 자문이 아니다.
