# 딜로이트형 한국어 보고서 만들기

이 스킬은 에이전트가 모은 자료(공시 원문, 설문 결과, 가격표, 기사)를 읽는 사람이 바로 판단할 수 있는 보고서로 바꾼다.
규칙은 취향이 아니라 계측값이다. 근거 수치는 `assets/layout.md`(판면·색·글자·그림표), `assets/titles.md`(제목), `assets/narration.md`(문장·문단), `assets/banned_words.md`(쓰지 않는 말)에 있다.

## 0. 시작 전에 확인할 것

1. **사실 목록이 있는가.** 보고서에 들어갈 숫자와 주장마다 출처(문서 이름, 쪽 또는 URL, 날짜)가 붙은 표가 먼저 있어야 한다. 없으면 보고서를 쓰지 말고 사실 목록부터 만든다. 출처가 없는 숫자는 보고서에 넣지 않는다.
2. **읽는 사람이 한 사람으로 정해졌는가.** 예: 「하이트진로에 처음 제안하는 광고대행사 AE」, 「발레학원 원장」. 읽는 사람이 정해지지 않으면 결론을 쓸 수 없다.
3. **결론을 한 문장으로 쓸 수 있는가.** 예: 「테라 라이트는 칼로리 1/3 감소를 근거로 퇴근 후 홈술 직장인에게 릴스로 제안할 수 있다」. 못 쓰면 자료를 더 정리한다.

## 1. 보고서 뼈대

| 순서 | 쪽 | 들어갈 것 |
|---|---|---|
| 1 | 표지 | 보고서 제목(판단을 담은 명사구), 부제(대상·범위·기간), 작성 날짜, 작성자 |
| 2 | 요약 | 핵심 메시지 3개. 메시지마다 숫자 1개와 비교 대상(전년, 경쟁사, 평균)을 붙인다 |
| 3~ | 본문 절 3~6개 | 절마다 결론형 제목, 리드 1~2문장, 그림 또는 표 1개, 해설 문단, 출처 줄 |
| 끝-1 | 시사점 | 읽는 사람이 다음에 할 일 3~5개. 「~해야 한다」, 「~할 필요가 있다」로 끝낸다 |
| 끝 | 출처·방법 | 자료 목록(이름·날짜·URL), 표본 수(n), 계산 방법, 자료가 없어 비워 둔 항목 |

본문 한 쪽에는 주장 하나만 둔다. 계측한 6,252쪽 가운데 2,051쪽(32.8%)이 그림·표와 글을 좌우로 나란히 놓았다. 그림 하나와 해설 문단 하나를 나란히 두는 배치를 기본으로 쓴다.

## 2. 제목 규칙(자세히는 assets/titles.md)

1. 이 절의 결론을 한 문장으로 먼저 적는다.
2. 결과 명사로 끝낸다. 방향 변화는 전환·재편·부상, 양 변화는 확대·둔화·가속, 할 일은 과제·필요, 갈림은 관건·핵심·변수, 예측은 전망·가능성이다.
3. 40자 이내, 명사로 끝낸다(실측 77.2%). 「~다」로 끝내지 않고(2.6%뿐), 「현황」·「개요」 같은 라벨로 끝내지 않는다(1.0%뿐). 줄표와 화살표로 끊지 않는다.
4. 좋은 예: 「저칼로리 맥주 시장, 홈술 직장인 중심으로 확대」, 「제안의 관건은 공시 수치의 출처 표기」.

## 3. 문장·문단 규칙(자세히는 assets/narration.md)

1. 문장 길이 중앙값은 72자다(25% 지점 48자, 75% 지점 107자). 주어와 서술어를 갖춰 끝맺는다.
2. 문장 끝맺음 비율은 단정·서술 19,259건, 유보·완화 3,982건, 권고·제언 2,640건, 전망·예측 1,374건이다. 확인된 사실은 「~했다」, 「~나타났다」로 단정한다. 제언은 시사점 절에 모은다.
3. 세 문장에 한 번은 숫자를 비교 대상과 함께 쓴다. 「30%가 도입했다」 대신 「전년 18%에서 30%로 늘었다」로 쓴다. 자주 쓰는 숫자 표현은 괄호 부연(10,655건), 퍼센트(5,261건), 증감 표현(4,862건), 연도(4,099건) 순이다.
4. 문단은 4문장·550자 안팎이다. 첫 문장은 앞 문단 없이도 읽히게 새로 열고, 둘째 문장부터 「이는」, 「또한」, 「특히」, 「반면」으로 받는다.
5. 처음 나오는 개념은 괄호로 정의하거나 영문을 붙인다(문장의 17.6%).
6. `assets/banned_words.md`에 적힌 표현은 한국 보고서 649만 자에 5회 이하로 나온 말이므로 쓰지 않는다.

## 4. 그림·표 규칙(자세히는 assets/layout.md)

1. 그림·표마다 위에 제목(무엇을 쟀는지), 아래에 출처 줄을 단다. 출처 줄은 「출처: 자료 이름(표본 n, 기간)」 형식이다. 계측한 출처 표기 1,012건 가운데 「출처」가 790건이다.
2. 그림 제목에는 기간(2024~2026), 표본 수(N=264명), 단위(억 원, %), 영문 병기를 필요할 때 괄호로 붙인다.
3. 그래프 색은 한 색 계열(진한 것과 연한 것 2~3단계)만 쓴다. 계측한 그래프 선 색 상위 4개가 모두 초록 한 계열이었다(#85bb24 5,827회, #354e09 4,450회, #92d050 2,264회, #25880d 1,422회). 자기 보고서에서는 초록 대신 자기 색 한 계열을 정한다.
4. 표는 가로줄만 쓰고 세로줄은 쓰지 않는다. 계측한 선은 가로 19,381개, 세로 4,969개다.
5. 숫자를 지어내거나 어림하지 않는다. 사실 목록에 없는 숫자는 그래프에도 넣지 않는다.

## 5. 판면과 글꼴

`template/report.html`을 복사해서 쓴다. 이 틀은 계측값을 그대로 담았다.
- A4 세로, 여백 위 29mm·아래 35mm·왼쪽 15mm·오른쪽 17mm(계측 중앙값).
- 본문 8.5pt(전체 글자의 38.3%), 그림·표 주석 7pt(11.3%), 소제목 10~12pt, 쪽 제목 14~18pt.
- 글자색은 거의 검정(#231f20)과 회색(#5f636a), 강조색은 한 가지다.
- 글꼴은 나눔바른고딕을 먼저 쓰고, 없으면 Noto Sans KR로 대신한다(계측 1위 글꼴이 NanumBarunGothic).
- 딜로이트 이름·로고·초록 브랜드색(#85bb24)은 쓰지 않는다. 형식만 빌리고, 표지와 머리글에는 자기 이름과 자기 서비스 이름을 쓴다.

## 6. 만드는 순서

1. 사실 목록(CSV 또는 표)을 읽고 0절의 세 가지를 확인한다.
2. 결론 한 문장, 요약 메시지 3개, 절 제목 3~6개를 먼저 써서 사람에게 보여 준다.
3. `template/report.html`을 복사해 절마다 채운다. 그래프는 HTML 안의 SVG나 Chart.js로 그리고, 숫자는 사실 목록에서 그대로 가져온다.
4. 본문 글만 텍스트 파일로 뽑아 검사기를 실행한다.
   `python3 scripts/check_korean.py 본문.txt`
   금지어가 걸리면(종료 코드 1) 고친 뒤 다시 실행한다.
5. 브라우저에서 HTML을 열고 인쇄 → PDF로 저장한다. 쪽마다 글이 판면 밖으로 넘치지 않는지 눈으로 넘겨 본다. 넘치면 글자를 줄이지 말고 쪽을 나눈다.
6. 마지막으로 보고서의 모든 숫자를 사실 목록과 한 번 더 대조하고, 대조한 개수와 다른 개수를 적는다.

## 7. 완료 기준

- 모든 숫자에 출처 줄이 있고, 사실 목록과 다른 숫자가 0개다.
- 쪽 제목이 모두 40자 이내 명사 종결이다.
- 검사기에서 금지어가 0건이다.
- 요약 메시지 3개가 모두 숫자와 비교 대상을 담고 있다.
- PDF로 인쇄했을 때 판면 밖으로 넘친 쪽이 0쪽이다.
